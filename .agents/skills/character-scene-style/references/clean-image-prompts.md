# 场景、人物与头发干净度提示词

用于用户要求画面干净、材质克制或减少碎纹理，以及当前采用参考已明确清爽表现的任务。与基础画风分开维护；按当镜可见内容将适用模块写入实际prompt。写实、毛绒、绘画等媒介按需调整，不把有意保留的毛发、笔触、污迹或纹理一概消除。

## 先分辨问题，不把所有问题当作随机噪点

| 可见问题 | 识别依据 | 生成端应明确的关系 |
| --- | --- | --- |
| 脏点、脏色 | 平滑区和暗部出现无意颗粒、彩斑、灰绿/灰褐污斑、无依据的斑驳 | 本材质应有的底色、自然色差、干净色面和连续过渡；保留合理环境反光，区别叙事需要的泥灰、汗珠和伤痕 |
| 碎 | 轮廓炸毛、散落碎片、极密小刻面/细线、高频亮点 | 连贯外轮廓，少量主组与有尺度层级的次组；不为此删掉必须保留的内容 |
| 乱 | 相同尺寸的形状重复堆叠、哪里都一样密、缺少走向 | 主体块与附属体块的大小、疏密、前后遮挡与生长/流动方向 |
| 明暗污染 | 大量细小亮暗来回跳、断裂高光、无形体依据的小块阴影，使材质显脏 | 按现有光源组织成片受光面和结构阴影，曲面宽缓转折，必要的硬边阴影保持；不把所有曲面压成单一亮暗两块 |

同一区域可以同时有几种问题。不能凭一个噪点值判定全部解决，也不把这张表当作固定频段、固定像素尺度或“模型能力上限”的定量结论。

## 场景干净度模块（含场景双铁律：时态物理拆分 + 净空三禁）

先保留原图的机位、景物占比、轮廓、位置、数量与遮挡，再组织场景内部的大小层级、疏密与明暗。近景必要材质可清楚，次要背景纹理克制；“少细节”不等于远近全糊。不得将云缩到三分之一、删树、减人、换构图或裁掉问题区当作保布局复刻的清理手段。

- **跨时态/事件物理拆分（`SCENE_TEMPORAL_STATE_CONFLICT`）**：跨时间线或重大事件状态变化（如和平/完好态 vs 战损/灾后废墟态）必须物理拆分为独立场景母图，严禁混用同一张场景母图。
- **净空三禁**：场景空镜母图严守净空三禁——① **旗杆留空禁挂旗帜**（仅留光杆或无旗状态）；② **禁现代交通标志**（禁八角 STOP 牌、现代路标、现代玻璃幕墙等错位标志）；③ **禁英文乱码与小字牌匾**。
- **净参考源帧喂入 `Ref 1`**：分镜生图优先将 `clean-source-frames` 裁除黑边与柔化角落台标后的 `ref_clean_frames/*_净参考.jpg` 喂入 `Ref 1`（`contact` / `review-grid` 接触表左列仍展示原片全貌）。

可用正向段：

```text
保留原有场景布局、景物占比、位置与遮挡。以主要体块和有大小层级的次级形组织建筑、地面、树冠与云体，轮廓连贯、疏密有序；受光面和结构阴影成片连贯，曲面保留宽缓自然的明暗转折与前后体积。墙面、天空、地面和暗部底色洁净，材质纹理只保留当前景别需要的尺度，不额外叠加脏污、碎亮斑或随机颗粒。
```

按需排除：无意斑驳墙皮、满地碎刻纹、密集点状叶影、云缘碎絮、均匀堆满小团块、阴影彩斑、过度锐化白边。剧情确需的旧墙、泥地、逆光树影等不默认消除；云的晴空案例数量与留白比例不推广到所有镜头。

## 人物干净度模块

皮肤、服装、配饰分别检查。脸色纯净不等于全脸同一颜色；保留已定骨相、面部受光与背光、眼窝、鼻翼、下颌和颈部接触阴影，允许正常红润及环境色。服装保留大衣褶、接缝、关键花边与身份配饰，金属保留能说明形体的反光；不要把脸、衣服和皮革一起磨成同样的光滑材质。

可用正向段：

```text
人物肤色和材质底色洁净自然，面部、颈部与手部的受光、背光及接触阴影有明确形体依据，色彩和亮度平顺过渡，保留动画骨相与三维体积。头发、皮肤、布料、皮革和金属的材质相互区分；衣褶和饰物按结构有序分组，必要轮廓与身份特征清楚，不额外添加非剧情需要的污斑、颗粒、碎亮点或密集小阴影。
```

按需排除：皮肤随机灰绿/灰褐斑、暗部彩噪、无依据的脸部碎阴影、过密毛孔/织纹、布料油亮碎斑、所有材质统一高光。腮红、雀斑、汗珠、疤痕、化妆与沾灰等若属于既定身份或当前剧情，需明确保留，不当作脏点自动抹除。

## 头发干净度模块：同时处理脏、碎、乱与碎亮暗

头发不只检查噪点。连续发型里若每一小束都单独亮一下、暗一下，或密密麻麻刻出等宽发丝，也会出现与场景同类的视觉脏感；去颗粒不能重组这些发束关系。

- **整体到局部**：先锁定原发型轮廓、长度、分缝、刘海、发饰和运动方向，再分出少量主要发束、从属中束与少量必要细丝。大小与疏密自然变化，不把一头发均匀切成同宽碎片，也不固定所有角色为同一束数。
- **明暗与高光**：发束按头颅、弯曲和遮挡塑形；高光沿曲面与发流形成连续、克制的带状或块状亮面。不要给每根细丝独立描亮边、叠密集亮暗细条，或把每一束都雕成尖锐小棱面；深发保留洁净分层的暗部，不靠整体提亮或洗灰降低脏感。
- **轮廓与细丝**：关键刘海尖端、发尾、自然卷和少量飞发保留；收束无意毛刺、发根噪线与整圈炸毛，不把轮廓修成等宽硬描边。
- **体积与身份边界**：保留层叠、遮挡、发束厚度及原有飘动，不改变卷直、长短、分缝、发色或缎带位置。不把头发模糊成色团、压成平面贴片，或合并成无分组的头盔、塑料块、橡胶条。

可用正向段：

```text
头发保持原有发型、分缝、刘海、发饰与发流方向，以少量清晰主发束和有尺度变化的次级发束组织形体，疏密有序，保留层叠遮挡、曲面厚度和三维体积。发束底色洁净，受光面与阴影连续，高光顺着发流形成克制、连贯的亮带或亮面；只在轮廓和关键位置保留少量自然细丝，不逐丝描亮，不均匀铺满小碎束。
```

按需排除：发根密集噪线、杂色脏斑、无数同宽尖碎发片、逐丝刻线与亮暗斑马纹、密集针状高光、无意碎闪点、轮廓整圈炸毛、塑料头盔、全头发涂抹。不得通过漂白发色、换发型、减发量或删发饰来掩盖问题。

## 组合、复核与处理边界

1. 在已定画风与原始内容之后，加入基础干净度，再按本镜可见内容选择场景、人物、头发模块。把选择的结构与光影要求写进实际完整prompt；不堆入不在画面的对象，不为了“高完成度”追加满画面的微材质词。
2. 实看整图，再看能判断问题的局部：背景与暗部交界；脸颊、额头、颈部和手；发根、发中高光与轮廓；衣褶和反光配饰。正常观看尺度的脏感与必要局部缺陷分别记录；不拿缩略图、放大后的单个像素或“prompt已写入”代替判断。
3. 同时复核**干净度、既定画风、三维体积**。如果看起来更干净但更平、糊、蜡、塑料，仍未达到目标。写实或刻意颗粒等用户指定媒介按其要求处理，不用本模块替换画风。
4. 按对画意和制作的实际影响判定，不能把所有偏差一律拦截。不影响画意、身份识别、动作与跨镜连续性的轻微色偏、局部偏亮、少量细毛/雨珠高光及轻微偏碎，可通过并简记，不为追求微观完美反复重绘。明显脏污、破坏形体的碎亮暗和内容错误另行处理。**已确认画风是底线**：从目标动画质感偏到游戏渲染、真人摄影或其他画法，属于画风错误，不能按“小问题”放行；要对照实际参考判断，不能仅凭“3D”标签或题材/昼夜差异定性。已被用户接受的具体图及残留以用户决定为准，不因规则升级自动重画。
5. 问题图处理、独立上下文、次数上限和重绘后审核遵循[生图质量规则](../../../rules/image-generation-quality.md)。本模块不授权滤镜补救或强制去噪。用户已明确要求的BAT阈值检查照原约定执行；skip(clean)只表示未触发随机噪声处理，不能证明发束、场景结构或视觉脏感通过。

以上为提示词与审核约束，不是新增实图验证结论，不承诺某词、某参数或某后处理能消除固定百分比的问题。下方云团模块只在相应场景条件下按需使用。

## 提示词交付结构

画风文档中将以下内容单独列出，方便复制及二次修改：

1. 基础画风正向词／负向词。
2. 画面干净度正向词。
3. 画面干净度负向词。
4. 本镜按需材质控制词。

人物和头发模块在出现对应内容时分别列明；不要只用“发束清晰”或“皮肤光滑”替代其结构、明暗与干净度要求。

实际生图提示词记录本次采用的完整组合及实际参考图。视频提示词采用当前项目已确认格式；默认按[视频提示词编写规则](视频提示词编写规则.md)写【全局设定】和逐镜执行内容。美术/景深/打光归入全局“视觉风格”，视频必要约束归入“禁止项”；不重新拆出旧“灯光氛围”字段，不把全部生图防错词塞进视频正文。干净度控制不取代角色差异化和统一画风。

## 干净度正向词：可复制基础段

```text
画面清爽，主体层次清楚，以完整的大形和连贯明暗组织画面；色彩过渡平滑，阴影通透分层。保留方向主光、结构阴影、体积感和空间纵深。眼睛、脸部与关键叙事道具清晰，次要表面纹理克制；减少无关的高频碎细节，边缘自然，不以整体模糊替代干净度。
```

## 干净度负向词：可复制基础段

```text
避免无意噪点、颗粒脏污、过度锐化、边缘白边、密集碎高光、杂乱斑点和无关刻纹；避免表面纹理抢夺主体注意力。禁止过度磨皮、蜡像感、全图失焦、整体灰平，以及为简化画面删掉必要人物、家具、道具或剧情信息。
```

## 材质控制：按镜头选用

| 对象 | 可选正向词 | 可选负向词与适用边界 |
| --- | --- | --- |
| 皮肤 | 面部形体明确，肤色过渡细腻，纹理尺度适合当前景别 | 不放大毛孔、粗糙凹凸或油亮斑点；写实项目保留自然肤质，不磨成塑料 |
| 头发／羽毛 | 连贯流畅的发束或羽片分组，轮廓有序，层次清楚 | 减少杂乱碎丝、尖刺、密集闪点；不抹掉角色特征和必要细节 |
| 毛绒／织物 | 毛束有序，疏密有层次，布料褶皱宽大柔软，绒感可读 | 避免全幅碎毛噪点、过密织纹；保留指定毛绒材质，不转换成光滑塑料 |
| 皮革 | 柔和哑光，清楚的大块结构与自然褶皱 | 避免密集压纹和破碎油亮高光 |
| 金属 | 宽阔连续的缎面高光，形体反射清晰 | 避免密集亮斑和无关刻纹；镜面或做旧要求优先 |
| 地面／雨水 | 少量宽软反射，雨线与水滴密度服务镜头重点 | 避免无意的满屏闪点；不改写必要天气强度、积水状态或动作线索 |
| 背景 | 用景深、光线和细节密度突出主体，空间结构可辨 | 不照搬海报式空背景，不删门窗、通道及必要叙事物件 |

## 使用与验收

- 根据本镜问题选词，避免在基础画风中同时要求“满画面极致微纹理”而又要求全面压低碎细节。
- “低局部对比”只用于无关表面微纹理，不压平全局光影、人物骨相或空间层次。
- 风格参考中的海报文字、专属构图、雨巷等具体内容不随干净度模块带入分镜。
- 实际看图检查：主体清楚、材质仍符合目标风格、空间与剧情信息完整，干净但不模糊。

## 场景结构与边界控制：按需追加

适用：云、树冠、草丛等次要景物因分组不明而出现脱落小块、边缘毛絮或填满留白。不是全场景固定后缀；不能为了干净删掉叙事所需物体或改动必须保留的原图布局。

### 场景结构模块

先明确对象种类与主形体，再给出合理的主组数量、所在位置和允许留空的区域；用“大块、连贯、饱满体积”组织主要形体，要求连续外轮廓，避免用无数零散小块补满空处。数量和留白必须服从原图/剧情，不固定为2个或65%。

晴空积云示例，只有允许重组云团时使用：

```text
2个主要积云团，分别位于画面左下和右下。每团是连成整体、饱满厚实的云体，以少数宽阔圆弧起伏组成；云底保留柔和蓝灰阴影和立体体积。
外轮廓以干净连续的整体形状为主，不出现脱落小云絮、丝状云、撕裂边或散云填缝。
约65%的画面为连贯的渐变蓝天留白，上右区域保持蓝天，不用零碎云片补满。太阳与主光位置按当前镜头。
```

英文同义模块：

```text
Exactly 2 massive solid cumulus cloud banks, 1 at lower left and 1 at lower right. Each bank is a connected, dense billowing volume with a few broad rounded lobes and a soft blue-grey shaded underside.
Clean, unbroken silhouettes. No wispy strands, detached tufts, torn fringes or scattered cloudlets.
Clear gradient blue sky occupies approximately 65% of the frame as negative space; the upper-right quadrant remains clear. Preserve cloud volume and the required sun position.
```

此示例不是把两团晴空积云套给战场阴云的指令。阴天、雨云、室内、树林和多人场景须按实际对象与叙事结构另定，保留必要遮挡、数量和空间信息。云种与体量、数量、轮廓和留白在本轮是一个组合，不能声称每个词已独立验证；数字写法本轮未与英文数词单独对照。

### 使用边界

云团数量、留白和结构词是按镜头选用的组合，不能声称每个词已独立验证，也不承诺稳定修复率。连续轮廓是验收目标，不能以提示词包含“干净”宣称碎边、白边、噪点或云内小团块已消除；仍须查看实图。额外压低云内微对比不作为固定必带词，不凭无关细节词推断具体问题的原因。

### 晴空光色与主次：按需模块

仅在允许调整景物体量且当前画风、时段和光照匹配时，按需使用主次体量、冷暖色面与纵向天空渐变；不把它们视为每张图的固定风格。

```text
仅在当前镜头允许调整景物体量时，形成一个主要云团和一个明显较小的次要云团，两者高度有区别，避免等大、等高的镜像呼应；保留必要位置和大片蓝天。
按当前主光方向组织完整受光面与阴影：云顶为有层次的暖白受光面，云体阴影为冷蓝灰，以宽阔色面塑形；保留当前三渲二的概括方式，不改成照片或全幅厚涂。
蓝天从画面上部较深的钴蓝向下方较浅的天青平顺过渡，无条带和随机颗粒；镜头仍然仰望天空，不为渐变添加地平线或地面剪影。
```

英文可选模块：

```text
When composition adjustments are allowed, use one dominant cloud mass and a clearly smaller subordinate mass with different crest heights. Preserve the required positions and broad clear-sky space; avoid equal-size mirror symmetry.
Follow the required main-light direction: warm off-white illuminated top planes and coherent cool blue-grey body shadows, expressed as broad stylized value families rather than photographic texture.
A smooth vertical sky-colour gradient, deeper cobalt toward the upper zenith and gently paler azure toward the bottom. Keep the upward-looking camera; do not add a horizon or ground silhouette.
```

不对称只是允许重新组织画面时的构图选项，不能违反原图必须保留的左右关系、数量或布局，也不是“干净”的普遍要求。冷暖分区服从当前场景时段和光源，不能把晴空暖白／蓝灰直接套到战场阴云、室内或夜景。

“3—4个大圆顶”、底部微暖反光及去白边等词不作为已验证有效的默认模块。若使用局部边缘柔化，只针对天然软性材质，不能把人物、道具轮廓和设计性硬阴影一起软化；自然受光亮边与全周等宽描边分别检查。

这些模块不取消高光、噪点、结构和画风验收，不承诺词语的独立因果或稳定成功率。提示词库里的示例不构成生产图采用依据。


## 场景与人物物理交互与环境光一体化（叙事驱动·按需调用原则）

在生图与视频制作中，**静态物理细节绝非千篇一律的教条或机械的“明令静止”，而是为角色的心理状态和戏剧叙事服务的工具**。只有当剧情需要强调特定的物理质感或心理张力时，才按需调用相应的物理描写，绝不全篇机械复制粘贴。

### 1. 核心原则：物理交互服从情绪与戏剧张力（按需选用）
- **需要强调“舒适、慵懒、卸下防备”时**：
  > `“人物身体深陷在厚实软包沙发的凹陷中，坐垫受重力自然包裹下沉，双肩彻底放松，营造出极具安全感的包裹感与舒适惬意。”`
- **需要强调“冷峻、戒备、随时爆发”时**：
  > `“人物身姿挺拔紧绷，仅身体前沿轻微抵住坐垫边缘，脊背离开靠背，双手如铸铁般锁死兵刃，呈现极度克制的临战张力。”`
- **需要强调“威严、沉默、如山定格”时**：
  > `“如静默雕塑般端坐，重心扎实沉稳，后方硬体沉寂受光，呈现不怒自威的凝重气场。”`
- **普通/非重点镜头**：保持文字清爽干脆，让画面视觉自然呈现，不生硬堆砌物理词汇。

### 2. 生图专用环境光一体化与物理焊接词（按需注入生图 Prompt）：
```text
全场景全局光照与物理空间一体化：人物与环境浑然一体、同源曝光；统一主光源方向自然映射在人物侧面受光面，背光面与暗部阴影完全浸润在环境漫射色温中；根据当前姿态自然呈现受力形变（如深陷沙发的包裹压痕或挺拔端坐的接触支撑），彻底杜绝孤立贴纸感与图层拼合感，人物自然扎根融入三维空间。
```

### 3. 生图专用负向提示词段落（Negative Prompt）：
```text
禁止人物浮空、禁止贴纸抠图感、禁止图层拼合硬贴、禁止人物与场景色温光影脱节（no disconnected lighting, no floating subject, no cutout sticker look, no mismatched color temperature）、禁止边缘硬切无漫射。
```
