# 生图：朝向与空间关系锁定

用于依据原片生成静帧、正反打、人物换入或用户指出朝向/站位错误时。身份图确定人物是谁；当镜的机位、身体姿态、头向和视线由原片及用户本轮要求确定。

## 提交前

实看目标源帧，必要时看前后连续帧；逐项写入实际生图提示词：

- **屏幕位置与裁切**：主体在画面左/中/右、主要占比、裁到肩胸还是腰部；不为展示身份图补齐画外身体。
- **身体方向**：胸口与肩线接近正对相机、轻侧还是明显侧身。不得用头向代替身体方向。
- **头部方向**：鼻尖指向画面哪侧，轻微转头还是三分之二侧面；低头/抬颌单列。必要时说明两眼是否都可见、近远脸颊的比例。不得把轻转画成整个人扭转。
- **视线目标与反摆拍向量**：眼球看向画面左/右/下方的具体人或物；眼睛向右不等于鼻尖和躯干也向右。看画外人物不等于直视镜头。分镜生图首句必须强锁真实俯仰角、核心叙事意象与非摆拍视线向量，**严禁生成正面盯镜头并排罚站摆拍**。
- **空间关系**：按人物姓名说明位于桌案哪一侧、同侧还是隔案相对、谁在前景遮挡谁。屏幕左右不能代替桌案两侧关系；同一侧的两人可仍有前后距离。
- **机位与净参考绑定**：相机从谁的正面/斜前/背后观察、眼平或俯仰；连续首尾沿用同一套已核机位说明，不从同段概述另造姿势。分镜 `Ref 1` 优先挂入 `clean-source-frames` 裁除黑边与柔化台标后的 `ref_clean_frames/*_净参考.jpg`（`contact` / `review-grid` 接触表左列仍展示原片全貌）。

“保持原方向”“按当前参考”“朝对方”对没有收到原片的生成引擎缺乏明确含义。原片仅供本地分析时，必须把这些关系转写成自足文字。以屏幕坐标说明画面左/右；涉及人物自身左手右手时单独标清，不能混用。

## 参考隔离与冲突处理

- 为每张附件标明职责；人物身份图的鼻向、仰视英雄姿态、扭腰、举臂和背景不能强制沿用。使用同一张脸不要求使用同一参考机位。
- 当参考姿态与当镜相冲突，在实际prompt中明确当镜身体、鼻尖、目光、手部和裁切，不只写“仅参考脸”。删除不必要的画外人物附件；朝向不符必须处理，不能靠改标签或简单镜像掩盖问题。符合生图质量规则时可对人物局部重绘一次；无法隔离、涉及场景或可能变脏时整张重绘，不使用错误候选作为正确姿态参考。
- 参考图可能造成姿态偏置只是诊断假设。先查实际提交prompt有无错向、表述歧义或与源帧冲突，不能未经对照就断言模型内部原因。
- 道具按此时剧情状态限定；同场景曾出现的肉、钱、豆粉等不能不分时刻重复加入。用户指定去掉时，明确允许清单及排除项，不能只删一个词后仍从背景附件带回。

## 生成后

逐图对照上述六项，首尾及正反打另核跨镜关系。重点看胸口/肩线、鼻尖、眼球三者是否分别正确，以及桌案是否错误隔开本应同侧的角色。仅角色姓名、服色正确不算朝向通过。问题记录真实偏差；从原始需求重绘次数及交用户审核的停止条件服从本地生图质量规则，不能自动覆盖正式资产。
