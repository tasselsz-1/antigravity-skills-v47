# 视频复刻技能版本更新

## v1.4.0 · 2026-11-08

联合版本：`character-scene-style`、`video-prompt-writer` 与主技能 `dual-drama-workflow` 同步升级：
- **主代理（root）绝对零看图与三层用完即焚子代理闭环**：主代理严禁在自身上下文打开源帧、参考图、生成图或接触表；看图写词、极简指针并发生图（≤100字参数）、【接触表+1K原图双检】审图当场改词与一次补救全部由独立子代理 + `batch_ops.py` 闭环完成。
- **双端第一棒/第二棒分工与一键回填**：角色“原名→新名”改名权唯一归属第一棒（Antigravity）并锁定于 `角色改名与音色映射.json`；第一棒编写 `第NN集_视频提示词.md` 时使用 `{{VISUAL_STYLE}}` 与 `【待填角色：...】` 占位符（自查豁免），第二棒（GPT/Codex）通过 `batch_ops.py fill-style` 0.1 秒一键回填。

## v1.3.1 · 2026-11-07

明确人物必须改名，并建立原名到新名的唯一映射；脚本、提示词、对白称呼、字幕、画内文字及人物/声线文件与索引同步使用新名。同一人物跨镜跨集保持一致，已确认的新名沿用，原名仅作内部追溯。两项skill入口显式列出规则。

## v1.3.0 · 2026-11-07

联合版本：character-scene-style 与 video-prompt-writer 同步更新。上一版为本聊天已确认发布的 v1.2.0，本版收录其后累计规则及引用文件的全部当前内容，不仅包含本轮6分钟切分与片头片尾调整。实际执行细节仍以各专题规则为准。

### 分集与正片范围

- 按原片时间轴每6分钟（360秒）切分正式集：0–360秒、360–720秒依次顺延，末集保留余长；集内再拆segment。
- 去除原片非剧情片头片尾，不新增片头包装、片尾字幕或结束卡；保留实际开头、结尾剧情及剧情字幕。
- 去除包装内容与增加生成过渡均不移动源片6分钟切点。删除“取原片前6分钟不等于成片6分钟”说明和旧3分钟拼集说明。

### 长剧目录、编号与七项交付

- 正式资产直接归属 `分集/第NN集/`，取消原EP目录层；完整源文件集中保留，精确源定位及历史编号存内部映射。
- 每集制作段从segment_01连续编号，段内镜头从镜头01编号；用项目、集号、段号联合识别资产。
- 七项交付为人物、声线、视频提示词、首尾及关键帧、Excel分镜头脚本、原视频段落、字幕时间轴。脚本和提示词直接放集目录。
- 生成前绑定目标位置，返回即保存并核验，完成后归位；“第N集交付文件”触发盘点、全剧复用、补缺和归位。已有适用人物、声线及在制结果优先复用，避免重复生成。

### 脚本、提示词与字幕

- 延续v1.2.0内置Excel模板及切分后生成脚本流程，增加源内容、对白、镜序、时间、公式、版式、引用与实际保存文件的自查。
- 脚本按场景供阅读，提示词按生成片段执行，两者通过内部映射关联，不要求逐行对齐；源片及源帧是画面依据。
- 台词按发言逐行标注段内时间；每segment最多4名说话角色，必要拆段后每段不少于4秒。
- 每集交付UTF-8 BOM字幕CSV，固定时间、人物、内容三列，使用本集累计时间；说话、心声及改名同步，未有成片时明确计划时间轴。
- 脚本、缺帧、提示词三项自查随相应产物生成或修改自动执行，跨文件变更复查受影响项并保存检查记录。
- 删除不增加具体信息的套话；保留剧情或设计需要的文字，不一概禁止文字、招牌或字幕；非用户要求的标识仍排除。

### 镜头、时间与帧图

- 保留原片机位、人物朝向、动作和空间关系；同空间优先可行运镜，逐处设计硬切衔接，转场明确实际过程并保留必要剪辑节奏。
- 新增过渡在承载镜头计时一次，后续生成时间顺延；段内至多一位小数，段尾普通四舍五入到整数，源时间精度独立保存。
- 帧名与当前提交用提示词绑定：每镜只取首帧，另加一张片段尾帧，第一镜头首帧兼片段首帧；不默认逐镜补尾帧或额外中间图。
- 缺帧检查按用途、内容、版本、可读性、实际路径和归位核验，不能只数文件。

### 人物、画风、生图与声线

- 人物复刻姓名、发色、服饰必改，发型、体型可改，主角以美型为主；采用身份与服装阶段跨镜一致，全剧范围排查不同人物同脸。
- 画风先实看参考并反推线条、色彩、阴影、材质等绘画语言；区分画风、身份、内容与布局参考，已授权生图修改提示词后衔接本轮验证。
- 默认内置ImageGen；干净度、独立上下文、影响判定、局部/整张补救及一次上限遵循全局生图质量规则。当前执行入口规定审核通过后按原授权推进，未通过或无法确定才交用户审核。
- 说话与心声使用不同音色，按角色与发声类型跨集复用；查音色库并试听，参考音频实际时长为2–3秒。
