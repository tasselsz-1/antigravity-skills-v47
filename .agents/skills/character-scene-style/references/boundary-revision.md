# 分段边界与二次修改

经验来源：聊天「10s切分提示词」（会话 ID：`01a0f13f-5064-7ff0-a797-cd876f0718dc`）。这里只提炼可复用的边界经验，不沿用该项目的角色、固定画风、平台、集数或历史授权。用户当前要求优先。

## 先划分，再复核修改

- 以约10秒为常用目标，实际目标和上限以当前任务及平台为准。先找真实硬切、换镜、场景转换，再在允许时长内选接近目标的切点；不要机械按每10秒拆开完整镜头。
- 初稿列出分段表：段号、原片精确起止时间或帧号、边界类型、出入镜状态。检查动作、对白、人物位置、视线、道具状态和切镜顺序。
- 二次修改聚焦有问题的边界及受影响的相邻段。保留无关的已通过成果，不把一次局部修正变成整批重做。调整后同步首尾帧、必要插镜、提示词、时间表和采用索引；旧版保留可恢复。
- 用户只要求审阅时先报告问题和建议；不要自动开始生图或重切原片。

## 原片边界与生成衔接

本节首尾帧指制作片段的首尾。原片画面确定内容，脚本整理场景分析，段内帧按当前提交用提示词镜头编号映射，每镜仅首帧，另交付片段尾帧；不要把跨片段硬切的双边界要求扩大为每个段内镜头都生成尾帧。用于原片分析的切前/切后抽帧可留中间文件，不自动成为生图任务。

- **真实硬切**：上一段尾帧取切前最后一张稳定无混帧画面，下一段首帧取切后第一张稳定无混帧画面。两张独立图分别命名、审核；不同镜头不要求哈希一致，不把原片硬切误记为连续镜头。若当前创作方案合理采用叠化或失焦过渡，仍分别保留两侧独立来源帧，并按生成衔接另记效果与加时；不得以效果替代源边界证据，也不为省图而抹掉应保留的蒙太奇。
- **连续镜头被迫拆分**：仅在时长上限等实际限制下使用。上一段尾帧与下一段首帧使用同一张边界图，交付副本哈希一致；下一段从该状态续演，不重复已完成动作。
- **效果转场**：与源片是否硬切分开记录。叠化使用两个独立画面；失焦可在完全虚焦时换到另一机位再对焦，不要求两个空间物理相通。转场安排在当前镜头内，按[视频提示词编写规则§4](视频提示词编写规则.md)额外计时并顺延后续区间；不自动合并独立生成segment。
- **硬切整改覆盖**：按共享规则§4逐处给硬切补合理衔接，覆盖段内与跨段。不能以独立机位、空间不相连或路径未核实笼统保留硬切；确需保留的冲击、反应、蒙太奇等切点在内部记录具体作用。效果衔接不要求两侧源帧一致，也不把源硬切记录改成源连续镜头。
- 必要插镜依据新机位、空间或人物关系、关键动作补齐，不把普通推近自动扩展成额外生图任务。

## 时间简化规则

当前默认以[视频提示词编写规则](视频提示词编写规则.md)为准：每个segment的生成时间从0秒开始，结尾按真实段长普通四舍五入到整数秒（非负数0.5向上），不是银行家舍入；段内镜头起止时间最多保留一位小数，即0.1秒精度，不限于半秒；源定位仍保留精确帧号/时间。不把段尾整数误解成所有镜头切点都必须整数。

- 原片定位、抽帧和对照剪辑保留精确帧号或时间戳。段内生成时间另列，明确二者对应关系；不将近似时间伪称为真实切点。不能拿全片累计时间的取整差冒充独立段长的普通四舍五入。
- 先换算为段内时间，同一镜头边界只计算一次，前后区间复用同一个值，区间连续不重叠。段尾取整后在允许范围内调整末态停留或节奏，不仅改标签而保留矛盾动作。若段长变为0、超过平台上限或损害关键内容，说明冲突并重新规划，不默默删剧情。
- 若生成节奏需要按简化时刻切换，同步调整对应动作区间和提示词；不能仅改标签而保留矛盾的动作或时长。
- 简化不能合并关键切镜、颠倒顺序、造成零长段、超过平台上限或截断关键动作。发生冲突时保留精确源定位，重新规划生成区间或可用末态停留，使正文段内至多一位小数、段尾整数；不为了格式删剧情、补动作或丢帧，无法兼容时说明具体冲突。
- 起点保持0；末段按实际可用内容处理，不能向上取整后声称原片存在额外画面。生成素材如需补足平台时长，单独标明生成长度与最终裁切长度。

旧有“小数≤0.2向下、0.2—0.7变半秒、≥0.7向上”规则只在用户明确继续使用该历史配置时启用，不覆盖当前段尾普通四舍五入规则。只改提示词格式时，不因此自动重切已采用边界或重生图片。

新增运镜或效果转场时，源片边界不随生成时间轴的扩时而移动。内部时间表分别记录源精确起止、原动作时长、新增过渡及新生成区间；取消转场时同步扣时。固定成片总长的例外与取整冲突处理以共享规则§4.2为准，不沿用“所有转场必须挤进原时长”的旧约束。

## 交付复核

检查原片对照切分无漏帧、无重复帧；生成时间轴连续、切镜顺序正确；硬切双图与连续共享帧规则分别成立。区分原片对照切分、彩图与提示词、AI视频成片，不把准备成果称为已生成视频。项目画风及人物资产由当前要求决定。
