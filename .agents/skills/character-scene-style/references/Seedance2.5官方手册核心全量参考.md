## 一、 硬件与多模态参数极限

| 模态类型 | 单次请求上限 | 推荐最佳区间 | 稳定性衰减/抽卡预警 |
| :--- | :--- | :--- | :--- |
| **图片参考** | 最多 30 张（4K 以内） | 1–5 张效果最佳 | 6–8 张稳定性下降，超 8 张需反复抽卡；多视角推荐多图输入 |
| **视频参考** | 最多 10 段，总时长 ≤ 30s | 单段 5–10s 效果最佳 | 超过 15s 稳定性下降；实际单视频限制 [1.8, 30.2]s |
| **音频参考** | 最多 10 段，总时长 ≤ 30s | 单段支持纯音频驱动 | 支持独立音色复刻与自动去除原视频 BGM 仅留人声 |
| **生成时长** | 单次延长支持 30s，套娃延长达 60s | 基础段推荐 4–15s | 超长视频模式最长支持 **180 秒无损续写** |
| **分辨率/宽高比** | 支持 480p 至 4K；帧率 [24, 60] fps | 宽高比 (0.4, 2.5) | 宽高长度限制 [300, 6000] px |

## 二、 官方三大核心结构公式（工业级粗模标准）

### 1. 【总述名称】
- **官方定义**：一句话描述整个视频的基调。
- **标准范式**：`[时长+镜头形式]([场景+角色+核心事件/基调])`
  - 范例：`29秒一镜到底(古装女子江边告别)`、`30秒一镜到底(科幻机甲追逐与变形)`、`30秒一镜到底(冰川穿越至深海幻境)`。

### 2. 【模块一：多模态参考层】
- **官方公式**：
  > `基于上传的[参考素材类型]，严格保持[......]一致，严格锁定[......]。`
- **官方多图职责分离铁律**：
  > `基于上传的[图片]，严格保持@图1的人物[面孔/特征]一致性，保持@图2的[构图/白模/空间关系]一致，严格锁定人物站位。`
  - `@图1`：专职锁角色面孔 ID、骨相、发型发色与固定制服；
  - `@图2`：专职锁空间透视、白模构图、环境光影与角色站位。

### 3. 【模块二：全局设定】(全局世界观 + 防崩坏)
- **官方六联公式**：
  > `[基础环境与质感] + [视觉风格] + [镜头语言] + [人物造型] + [表演核心] + [禁止项]`
  1. **基础环境与质感**：`[时间] + [地点] + [氛围] + [强调极致的真实物理质感与光学表现]`；
  2. **视觉风格**：`[美术基调/写实/二次元] + [主色彩] + [景深随镜头切换] + [具体打光方式]`；
  3. **镜头语言**：`[景别/视角] + [详细描述与机位死锁，避免自作主张跳切]`；
  4. **人物造型（七维解剖学）**：`[年龄/种族]` + `[肤色/皮肤质感(必带真实微细毛孔肌理)]` + `[面部骨相五官]` + `[眼神/灵魂]` + `[发型/发色(发丝微风轻拂)]` + `[服装/面料质感]` + `[体型/气质]`；
  5. **表演核心**：动态动量序列（眼神流转、呼吸起伏、下颌咬紧、喉头吞咽等解剖学微反馈）；
  6. **禁止项**：四维防崩坏（声音 + 字幕 + 行为 + **时序状态门控锁**）。

### 4. 【模块三：时间戳剧本分镜】(精准导戏微切片)
- **官方三阶公式**：
  > `[开始秒数 - 结束秒数] + [核心阶段/主题]`
  > `[动作/表情 等物理层面指令]：[景别] + [构图] + [人物细节动作]`
  > `[情感解析或者镜头调度 等维度的潜台词]：向 AI 解释对物理层面指令的深度表达意图`
  > `可根据实际情况添加【切镜/转场参考 prompt】`

## 四、 官方【白模控制（Clay Render）】五段式提示词公式

> 适用场景：利用 3D 白模、火柴人分镜、多宫格线稿视频，控制复杂运镜、角色站位与动作轨迹，从零渲染成片。

### 1. 粗颗粒度白模（低保真几何体/火柴人动线）
- **总公式**：`【参考声明】+【对应关系映射】+【剧情详述】+【场景处理】+【整体收束】`
  1. **【参考声明】**：`参考[视频1]的{运镜 | 动作 | 动线 | 光影变化 | 角色站位 | 音乐音效 | 画面节奏}`
  2. **【对应关系映射】**：`将[视频1]中的{颜色/形状特征}模型替换为[图X]的{角色名}，{颜色/形状特征}模型替换为[图Y]的{道具/场景名}`
  3. **【剧情详述】**：`按时间线或逻辑顺序详细描述剧情，包括动作、微表情、台词、光影变化`
  4. **【场景处理】**：`可以使用单纯文字描述，或者背景场景使用[图W]的{场景描述}`
  5. **【整体收束】**：`{整体画风基调}，{画质要求}，{一致性约束}，{音频处理}等`
  - **官方避坑指南**：粗颗粒度模型若有四肢或翅膀，必须在提示词中逐秒写出完整动作序列，避免模型动作僵死；最佳实践是**不上传带四肢翅膀的模型**，仅用简单体块指导动线。

### 2. 细颗粒度白模（高精度 3D 模型材质/光影替换）
- **总公式**：`【渲染指令】+【分段渲染描述】+【场景处理】+【整体收束】`
  1. **【渲染指令】**：`将[视频1]的白模动画渲染成最终成片。`
  2. **【分段渲染描述】**：`0-{N}s：{渲染要求——背景环境、色调氛围、人物材质、光影效果}；{N}s {转场触发点与方式}：{转场后新场景的渲染描述}`
  3. **【场景处理】**：`文字描述或参考图绑定。`
  4. **【整体收束】**：`新场景环境、人物渲染保持不变/随场景变化。`
  5. **官方避坑指南**：上传参考视频前，**必须去除轨迹线、三维坐标轴、相机 Cone 锥体等 3D 软件辅助参考线**，防止模型将参考线渲染成实体几何物体。
