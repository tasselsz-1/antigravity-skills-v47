# 人物与场景替换式复刻

源于聊天「10s切分提示词」及其项目文档《替换式剧情与镜头复现规则》《原动漫剧情复刻_通用流程_v2》。这里只提炼通用方法；原项目的角色、固定画风、平台和历史授权不自动沿用。当前用户要求优先。

## 复刻目标

保留原剧情、事件顺序、人物关系、关键动作、对白原意和切镜意图，以当前采用的新人物、新场景及目标画风重新呈现。允许外观和构图适配，不要求逐像素相同，也不自行新增剧情或改变事件结果。

## 四类参考职责

| 来源 | 负责 | 不自动继承 |
| --- | --- | --- |
| 原片镜头 | 剧情、切镜顺序、机位、景别、构图意图、人数、动作接触、视线、空间方向、关键道具操作 | 旧人物脸、旧布景装饰、原片材质与画风 |
| 当前采用人物图 | 新脸型、五官、发型、体型、服装、配饰及必要状态 | 参考图自带的场景、机位或不适用姿势 |
| 当前采用场景母图 | 新空间布局、门窗入口、固定家具、通道、材质、主光方向 | 母图机位对当前镜头的强制覆盖 |
| 当前画风参考与提示词 | 本项目的渲染方式、材质语言、色彩及完成度 | 参考人物的脸、海报构图、文字等无关内容 |

组合原则：`原片画面内容、构图与动作状态 + 已确认的人物/场景替换 + 当前目标画风 = 新分镜图`。先实际查看原片和目标源帧，脚本用于按场景整理分析，当前提交用提示词用于执行及编号命名；遵循[原片依据与脚本映射规则](项目基本结构以及规则.md)。用户明确确认的改动优先于原片对应内容，脚本或提示词中的未经确认偏差不能自行成为改画依据。

## 人物复刻设计要求

- **必改项：姓名、发色、服饰（原型真容题材除外）。** 常规复刻相比原片角色，人物姓名必须修改，头发颜色必须改变，服饰必须重新设计。发型本身不属于必改项。若项目属于**真人原型/历史人物 1:1 锁脸复刻**，须先经 `prep-prototype-refs`（`prep-historical-refs`）做真水平镜像（SHA256 校验）与胸像裁切，`_肖像.png` 强制免冠露额 1:1 复刻发际线、头骨轮廓、脸颊肥瘦与真实年龄（严禁美颜/硬汉模板），并经 `prototype-sheet`（`historical-sheet`）三列对照表把关通过后方解锁 `_主体.png` 与 Stage B（`save-unit` 级联阻断）。
- **跨时态场景物理拆分与净空三禁：** 同一空间若存在跨时间线或重大事件状态变化（如和平/完好态 vs 战损/灾后废墟态），必须物理拆分为独立场景母图（混用触发 `SCENE_TEMPORAL_STATE_CONFLICT`）；场景母图严格执行净空三禁（旗杆留空禁挂旗帜、禁现代交通标志、禁英文乱码与小字牌匾）。
- **分镜净参考与反摆拍：** `clean-source-frames` 裁除黑边与柔化台标生成 `ref_clean_frames/*_净参考.jpg` 喂入 `Ref 1`（`contact` / `review-grid` 左列仍展示原片全貌）；分镜首句强锁真实俯仰角、核心叙事意象与非摆拍视线向量，严禁正面盯镜头并排罚站摆拍。
- **可改项：发型、体型。** 可按目标画风、角色身份及表演需求调整；调整后仍须保留剧情所需的年龄阶段、行动能力与关键动作关系。
- **主角以美型为主。** 优先高挑、修长、清秀或俊美的形象，结合角色身份与目标画风设计，保持不同角色的面部辨识度。
- 建立“原角色姓名/身份ID→新角色姓名/身份ID”唯一映射，别名、称呼及对白中提到的姓名同步对应。脚本、提交用提示词、对白中的称呼、字幕时间轴、画内文字、人物与声线资产名称、参考清单及索引统一使用新姓名；自查核对原名残留、错名和跨集映射。精确源记录保留原姓名用于追溯，未采用候选和历史审核记录不倒改。无名群演仍按稳定代号管理，不为改名强行编造姓名。
- 设计时明确记录原名与新名、原片与新角色的发色和服饰差异，以及发型、体型是否调整；文本自查核对改名映射，生成后实际看图核对外观必改项，不能仅靠提示词声称已改。
- 以上用于建立或按要求重设计人物；采用后跨镜、跨段、跨集沿用同一适用身份与服装阶段，不为每次出图重新换色、换装。干净度规则中“保持发色、发型”等指保持当前采用版，不要求恢复原片造型。已采用资产不因本次规则更新自动重绘；用户对具体角色明确指定的保留或例外优先。

## 替换准备

- 先逐镜核实剧情、对白、角色、场景、道具和动作，再建立“原角色→新角色”“原地点→新场景”的采用映射，注明服装/道具状态及当前版本。已识别角色在提示词中用正式姓名，无法确认的画外局部不擅自命名。
- 主要人物先确定身份主图，必要时补全身、服装阶段或复杂动作状态。跨镜使用同一采用身份；清晰露脸配角保持个体差异，远景群演、背影不无条件扩建身份图库。
- 人物资产可以按文字设定从零创建，也可以采用用户提供的对应角色图，或基于该图按要求修改后采用。参考图已有合适身份信息时直接复用，不强制重做主图；先区分保留身份、仅参考特征和重新设计三种意图。
- 同一空间有多个重要视角时，先确定场景母图，再按原片镜头意图匹配新场景机位；单一视角不必机械补齐整套场景。门窗、入口、家具、通道及光照在新场景内部保持一致。
- 明确可复用、必须新增、条件性补图清单；不因每个镜头变化无限扩建资产。

## 镜头复现与适配

- 每镜明确人数、身份、站位、朝向、画面占比、相机位置、关键道具数量与归属、身体左右侧、动作起止状态和遮挡关系。
- 新体型、新布景可以适度调整主体占比、尺度和边缘裁切，但不能无故改变人物关系、关键动作、道具数量、身体侧、进入路径、空间方向或事件结果。用户已接受的适配不擅自改回。
- 新场景与原片布局不同时，保持正式新场景的空间自洽，并适配原镜头叙事目的。若两者无法兼容且必须改变关键剧情或动作，先提出具体冲突供用户决定。
- 依据原片对应画面、动作及用户确认的替换要求生图，按当前提交用视频提示词的片段及镜头编号准备、命名各镜头首帧，并补当前片段尾帧；首个镜头首帧兼片段首帧，已有适用图直接复用。段内每镜不另补尾帧，普通推近、表情或动作阶段不自动拆镜或增加中间图。跨片段硬切双边界按 [boundary-revision.md](boundary-revision.md) 执行，不能扩展成段内逐镜双图。
- 生图时只选本镜必要且互不冲突的参考，并写清职责。原片外貌或画风污染新设计时，先人工转写镜头结构、减少冲突附件再生成；工具不支持权重时，不声称设置了数值参考权重。

## 二次修改与审核

- 优先检查剧情/动作/人数/身份，再查空间、人物状态、目标画风、道具接触与跨镜连续性；实际看图验收，不能仅根据提示词判断完成。
- 按[生图质量规则](../../../rules/image-generation-quality.md)处理：影响表达、剧情、镜头变化或朝向/场景/人物一致性的错误必须补救；无影响的细微差别可通过。非噪点、非场景的局部内容问题，能保持干净度时允许局部重绘一次；场景和噪点问题整张重绘。局部与整张重绘共用一次上限；初图与补救图经独立审图子代理双检通过后免逐图展示并自动归位推进，仅将一次补救后仍未通过或无法确定的图片汇总提交用户审核。
- 局部返工只处理受影响镜头及相邻连续性，同步当前采用图、视频提示词、边界图和索引。保留旧稿及实际生成记录，不倒改历史调用提示词。
- 不因正常色偏、不可见区域或细微材质差异反复生成，也不为简化画面删掉必要剧情信息。原片疑似穿帮先指出，由用户选择保留或修正，不能自行改写剧情。
