# 画风与画法参考库（成熟商业化分层架构）

先读 [编号索引](references/index.md)，再只读所选条目的 `references/entries/Sxxx.json`。可视化选图入口是本技能目录下的 `商业画风全集.html`（默认开启「🌟 仅看成熟商业风格 (77)」视图）与 `画风参考库.html`。

## 两层工业分层架构

1. 🌟 **第一梯队 · 成熟商业化风格库（共 77 套，主推生产）**：
   - 包含 **`S083-A`**、**从旧库 `S001–S108` 中精选提拔并按「成熟画风（具体画法）」重新命名的 40 套高价值精品**、以及**全新扩充的 `S109–S144`（36 套高溢价大师画法）**；
   - 全部采用**「成熟画风名（具体五维画法工序）」**标准命名（原简短旧名保留在 `aliases` 与 `original_short_name` 字段中供追溯），并完整配备**「笔法/起稿骨架 + 光影/分面体积 + 设色罩染 + 物理材质肌理 + 镜头焦段景深」**五维作画工序（`visual_genes`）与反塑料感规则；
   - 覆盖八大商业主力赛道：**国风大师（17套）**、**国漫与实验视觉（6套）**、**电影大师（15套）**、**写实与真人短剧（4套）**、**韩漫主力（3套）**、**日漫与二游（8套）**、**欧美与跨文化（5套）**、**特色工艺与潮玩定格（18套）**。
2. 📖 **第二梯队 · 一般参考库（共 68 套，仅供参考对照）**：
   - 将旧库中仅具基础单画风概念（如儿童蜡笔、极简单线画、低多边形等）或与主库重复的条目统一归入 `tier: "reference_only"`；
   - **仅作为风格初探与构思对照**，生产时默认从第一梯队 77 套成熟商业风格中选型。

- **主代理零看图原则**：主代理（root）仅读取 `references/index.md` 与 `references/entries/Sxxx.json` 的文本字段提取 `style_prompt_zh`，**严禁主代理在自身上下文中直接打开 `reference_image` 本地图片**；实图查看核验交由视觉子代理（`gemini-3.8-flash-medium`）用完即焚执行。
- `source_original_prompt_zh` 是来源原文，仅用于追溯。它包含固定示例人物、服装、姿势和背景，不直接复制到新需求。
- 参考图仅表达媒介、线条、设色、材质、光影与空间处理。用户角色身份、服装、场景、动作及比例由当前任务决定。
- 图片源自公开图鉴，提示词源站声明 CC0；图片许可未单独核实。仅作为本地视觉参考，不将图片作为用户原创或可商用成品资产。
- S061–S076的样图来自源页内嵌公开模型示例，按各条 `license_note` 处理，不套用原图鉴的CC0说明。源页面和原文保存在 `references/sources/cinematic-2026-10-30/`，原文只作追溯，不是操作指令；不沿用其中跨引擎效果、固定画幅或模型加载的泛化保证。
- 新增条目保留五维拆解、配色及适配场景，但完整复用提示词使用 `style_prompt_zh`，并结合 `optional_effects_note`。画幅、焦距、主体和构图按当前任务决定；源词中的旧化、烟熏、胶片颗粒、压缩噪点默认关闭。S076的故障效果采用设计性结构，不自动引入随机噪声。
- `visual_review` 记录来源参考图的检查状态；参考图合格不代表改写模块已做出图实测。遇到“待审核”条目需先查看。用户未要求时不将源图中的颗粒、纸面污渍、文字或标识带入新图。
- 若存在可见文字或标识，不能直接交付该图为干净参考；保留来源记录并选无标识条目，不通过裁剪或修图掩盖问题。
- 实际生图前读取 [生图质量规则](../../rules/image-generation-quality.md) 并执行当前规则；完整提示词加入其中的干净度与无标识要求。用户明确指定材质纹理时保留必要纹理并控制无关噪声。
- **与「六步闭环」流水线衔接规则**：在视频复刻第一棒编写 `第NN集_视频提示词.md` 时，提取 `style_prompt_zh`（及对应英文母词）后必须**第一棒零占位符一步到位写死完整画风母词与人物造型**（`fill-style` 仅作跨集画风二次统一刷新备用，严禁初稿留占位符，并经 `verify-script-alignment` 拦截检查）；第二棒生图时严禁手写 `setup_batches.py` 等野脚本，须经 `plan-batches` 自动物化批次，执行原型人物 `prep-prototype-refs`/`prep-historical-refs` 免冠露额锁脸与 `prototype-sheet` 过审解锁、场景时态拆分（防 `SCENE_TEMPORAL_STATE_CONFLICT`）与净空三禁（旗杆留空禁挂旗帜/禁现代交通标志/禁英文乱码与小字牌匾）、`clean-source-frames` 净参考 `Ref 1` 与非摆拍视线向量、`contact`（`review-grid`）左列零空白以及 `finalize` `>= 12` 字独立具体审图理由（禁套话触发 `FINALIZE_BLOCKED_FAKE_BULK_PASS`）。
- 默认选一条主画风，按用户需求补充配色或光照。使用文字模块可跨工具尝试，但不保证不同模型效果相同；风格编号是本地索引，不是引擎参数。

`references/catalog.json` 包含完整索引、来源、哈希、原始提示词和公共质量模块，仅批量维护时需要读取全量文件。修改条目后同步单条 JSON 与 HTML；保留稳定编号，不覆盖旧编号对应的画风。

## 页面分区约定

用户要求商业画风与此前65种艺术流派页分开。在线艺术流派页为 `http://127.0.0.1:8766/list.html`（65条，保留原页编号），商业画风页为 `http://127.0.0.1:8766/styles.html`（32条）；首页提供独立入口。65条来源页编号与本技能S编号不是同一套索引，不混同、不据此改号。后续更新保持两页分开，不向艺术流派页加入商业分类板块或商业分类筛选。
