## 一、 核心设计标准：7 维人物设计公式模板（真人 & 动画通用）

> 详细细分公式与参考举例见 [`references/character-design-template.md`](references/character-design-template.md)。

```text
人物 = [1. 年龄 / 种族]
     + [2. 肤色 / 皮肤质感]
     + [3. 面部细节特征]   ← 参考本库 B001–B024 骨相维度改写
     + [4. 眼神 / 灵魂]
     + [5. 发型 / 发色]     ← 参考本库 H001–H042 发型维度改写
     + [6. 服装 / 服装材质]
     + [7. 体型 / 情绪 / 气质]
     + [其他要求]（如有）
```

| 维度 | 细分公式骨架 | 核心作用 |
| :--- | :--- | :--- |
| **1. 年龄 / 种族** | `[具体岁数] + [具体国籍/人种] + [风格形容词] + [脸型名词]` | 锁定人物年龄基调、人种与基础脸型 |
| **2. 肤色 / 皮肤质感** | `[冷暖色调] + [具体肤色名词] + [皮肤质感形容词] + [强制保真后缀：保留真实的微细毛孔与肌肤纹理（可增加雀斑/瑕疵）]` | 避免“AI 磨皮塑胶白”，增强真实肌理 |
| **3. 面部细节特征** | `[眼型描述] + [眉骨特征] + [鼻梁特征] + [唇形特征] + [下颌线/骨相特征]`（至少 3–4 点组合） | **决定辨识度与防同脸**（参考 `B001–B024`） |
| **4. 眼神 / 灵魂** | `[眼神形容词] + [目光传达的信息/比喻] + [透出的深层情绪]` | 赋予人物情绪内核与戏剧张力 |
| **5. 发型 / 发色** | `[具体发色] + [头发状态/质感] + [具体发型名词] + [环境与动静补充（如被风吹/凌乱）]` | 拒绝单调词，展现状态、质感与剪影（参考 `H001–H042`） |
| **6. 服装 / 服装材质** | `[繁简/剪裁] + [颜色] + [具体服装名词] + [布料材质/新旧状态] + [穿着方式/细节]` | 从面料与剪裁侧面烘托身份气质 |
| **7. 体型 / 情绪 / 气质** | `[骨架/肩部特征] + [构图/镜头要求] + [人物动作/视线] + [整体散发的氛围词]`（若故事 Prompt 已有镜头/动作，则省去构图与动作） | 决定骨架体态、画面构图与故事氛围 |

## 三、 维护与合规原则

- **主代理零看图原则**：根主控窗口仅读取 `references/character-design-template.md`、`references/index.md` 与单条 JSON 文本，严禁直接查看 `assets/` 下的参考图；如后续配白底参考图，由视觉子代理负责核验。
- **防直接套用检查**：从本库汲取维度灵感后，必须按 7 维模板结合剧本人物年龄、肤质、眼神、环境动态与服装材质重新撰写完整设定，确保每个角色拥有独一无二的完整 7 维画像。
- **增量同步命令**：修改数据后运行 `python <WORKSPACE_ROOT>/.agents/skills/character-face-hair-reference/scripts/build_library.py` 同步生成 `catalog.json`、单条 JSON、`index.md` 与 `人物骨相与发型库.html`。
