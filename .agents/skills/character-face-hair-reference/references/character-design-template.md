# 人物设计公式模板（参考标准 · 真人与动画人物通用）

> [!WARNING]
> **使用说明**：本模板用于指导编写高质量、高辨识度、反“AI 塑胶网红脸”的角色描述；所有下方示例及本库 `B001–B024`、`H001–H042` 均**仅作参考，不可直接复制照搬使用**，必须结合具体剧本角色逐维原创改写。

---

## 总体公式

```text
人物 = [年龄 / 种族] + [肤色 / 皮肤质感] + [面部细节特征] + [眼神 / 灵魂] + [发型 / 发色] + [服装 / 服装材质] + [体型 / 情绪 / 气质] + [其他要求] (如有)
```

---

## 各维度细分公式详解（7 维）

### 1. `[年龄 / 种族]`（人物基调）
> 写明具体年龄段、人种、脸型风格。

- **细分公式**：`[具体岁数] + [具体国籍 / 人种] + [风格形容词] + [脸型名词]`
- **参考示例（不可直接照搬）**：
  1. 22 岁东亚女性，清冷古典的丹凤脸；
  2. 25 岁英国男性，瘦削高傲的英伦贵族脸；
  3. 26 岁非裔黑人女性，骨相极其立体的黑珍珠超模脸。

---

### 2. `[肤色 / 皮肤质感]`（避免磨皮白，增强真实感）
> 写明色调与真实肌理。

- **细分公式**：`[冷暖色调] + [具体肤色名词] + [皮肤质感形容词] + [强制保真后缀：保留真实的微细毛孔与肌肤纹理（可增加雀斑 / 瑕疵）]`
- **参考示例（不可直接照搬）**：
  1. 冷调白皙肤色，透出细腻的温润玉石质感，保留真实的微细毛孔与肌肤纹理；
  2. 暖调蜜糖色，带有阳光照射后的光泽感，鼻梁处有淡淡的真实雀斑，保留微细毛孔与肌肤纹理；
  3. 粗糙的小麦色皮肤，带有风霜感与细微的干纹，保留真实的粗大毛孔、胡茬质感与肌肤纹理。

---

### 3. `[面部细节特征]`（决定辨识度 · 可参考本库 `B001–B024`）
> 写明人物面部细节（**至少写 3–4 点组合**）。

- **细分公式**：`[眼型描述] + [眉骨特征] + [鼻梁特征] + [唇形特征] + [下颌线 / 骨相特征]`
- **参考示例（不可直接照搬）**：
  1. 细长的桃花眼（眼眶微润），鼻梁小巧挺直，唇部丰润且嘴角带着若有若无的浅笑，下颌线条柔和；
  2. 微微上挑的丹凤眼，折叠度极高的立体眉骨，鼻梁高挺光洁，颧骨微凸，下颌线像刀削般清晰利落；
  3. 圆润的杏眼，眼睑下至带无辜感，鼻头微翘略带肉感，饱满的唇珠，脸颊带有轻微的婴儿肥，面部线条流畅。

---

### 4. `[眼神 / 灵魂]`（决定情绪）
> 写明目光传达的信息，传达情感。

- **细分公式**：`[眼神形容词] + [目光传达的信息 / 比喻] + [透出的深层情绪]`
- **参考示例（不可直接照搬）**：
  1. 眼神极其深情、含情脉脉，眼底仿佛有一汪春水，目光温柔而专注，透着深深的眷恋与一丝不舍；
  2. 眼神极为冷静、空洞，像深不见底的黑洞，目光锐利且极具压迫感，透着一丝难以捉摸的危险气息；
  3. 眼神涣散、暗淡无光，目光低垂没有焦点，透着深深的疲惫与对生活的麻木感。

---

### 5. `[发型 / 发色]`（拒绝单调词，展现状态与质感 · 可参考本库 `H001–H042`）
> 写明头发的状态、质感与造型。

- **细分公式**：`[具体发色] + [头发状态 / 质感] + [具体发型名词] + [环境与动静补充（如被风吹 / 凌乱）]`
- **参考示例（不可直接照搬）**：
  1. 乌黑的发丝盘成随性典雅的古典低盘发，仅用一支素色玉簪固定。几缕细碎的鬓发不经意地垂落在脸颊边缘，随着微风轻拂；
  2. 焦糖棕色的微卷长发，呈现刚睡醒的自然蓬松与凌乱感，几缕发丝随意地搭在锁骨处；
  3. 银白色的齐耳短发，带有强烈的哑光偏光质感，发丝边缘锐利，紧贴头皮。

---

### 6. `[服装 / 服装材质]`（展现风格）
> 写明具体的款式、材质与新旧状态，从侧面烘托人物特性。

- **细分公式**：`[繁简 / 剪裁] + [颜色] + [具体服装名词] + [布料材质 / 新旧状态] + [穿着方式 / 细节]`
- **参考示例（不可直接照搬）**：
  1. 极简的素白色交领古装，布料带有柔软光泽的素雅真丝或轻纱，衣领处微微敞开，无多余刺绣；
  2. 宽大的做旧深棕色机车皮夹克，皮革表面带有真实的自然折痕与金属拉链反光，内搭一件洗到发白的灰色 T 恤；
  3. 剪裁极其修身的深黑色双排扣西装，采用挺括的高级羊毛精纺面料，搭配酒红色真丝领带，一丝不苟。

---

### 7. `[体型 / 情绪 / 气质]`（决定画面构图与故事感）
> 写明骨架特征、画面构图以及整体散发的氛围。

- **细分公式**：`[骨架 / 肩部特征] + [构图 / 镜头要求] + [人物动作 / 视线] + [整体散发的氛围词]`
- **分镜适配规则**：若整体故事 Prompt 中已包含对构图、镜头、人物动作的描写，可去除 `[构图 / 镜头要求] + [人物动作 / 视线]`。
- **参考示例（不可直接照搬）**：
  1. 身姿纤细，双肩削瘦。胸部以上的半身特写构图，眼神直视镜头。整体散发出一种温婉婉约、深情楚楚的古典浪漫气质；
  2. 骨架宽大，肩膀厚实微圆。低机位仰拍的全身构图，人物侧身站立回头看向镜头。整体散发着一种在绝境中求生的坚毅、悲壮的电影史诗感；
  3. 身形修长挺拔。面部大特写构图，半张脸隐没在阴影中。整体散发着神秘危险、令人窒息的惊悚电影主角气质。

## 完整组合范例（仅作结构对照参考，不可直接使用）

- **[年龄 / 种族]** 22 岁东亚女性，极具古典韵味的温婉电影脸。
- **[肤色 / 皮肤质感]** 冷调白皙肤色，透出细腻的温润质感，保留真实的微细毛孔与肌肤纹理。
- **[面部细节特征]** 细长的桃花眼（眼眶微润），眉心微微舒展，鼻梁小巧挺直，唇部丰润且嘴角带着若有若无的温柔浅笑，下颌线条柔和。
- **[眼神 / 灵魂]** 眼神极其深情、含情脉脉，眼底仿佛有一汪春水，目光温柔而专注，透着深深的眷恋与一丝不舍。
- **[发型 / 发色]** 乌黑的发丝盘成随性典雅的古典低盘发，仅用一支素色玉簪固定。几缕细碎的鬓发不经意地垂落在脸颊边缘，随着微风轻拂动。
- **[服装 / 服装材质]** 穿着极简的素白色交领古装，布料是带有柔软光泽的素雅真丝或轻纱，衣领处微微敞开。
- **[体型 / 情绪 / 气质]** 身姿纤细，双肩削瘦，散发出一种温婉婉约、深情楚楚的古典浪漫气质。特写构图，眼神直视镜头。
