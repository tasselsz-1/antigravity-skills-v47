# 旧六字段格式兼容附录

视频复刻任务先完整读取[视频提示词编写规则](../../character-scene-style/references/视频提示词编写规则.md)，采用其中的【全局设定】及逐镜“动作/物理指令、台词、音效”格式和人物动作完整性检查。下方六字段为旧版参考，仅在用户明确要求该格式时使用；即使使用旧格式，也必须在“画面”字段写明人物的起始状态、具体动作过程和结束状态，不能只写运镜、站位或情绪。

优先沿用用户提供的参考文档格式。没有另行指定时使用共享规则的【全局设定】＋逐镜三字段。以下六字段结构只在用户明确要求旧格式时使用。仅指定字段格式不表示授权生成音乐。

```markdown
# [项目名]｜分段视频生成提示词

## 统一风格
[固定角色、材质、画幅、场景、色彩、渲染方式和连续性规则。]

> 说明：[片段数量、编号缺口、末段时长、台词语言和待核内容。]

## segment_01｜[简短剧情标题]

**镜头：** [景别、机位、运镜、节奏、转场与首尾衔接。]

**灯光 氛围：** [环境、时间、材质、光线、色调、视觉风格与情绪。]

**画面：** [按时间顺序描述角色位置、动作、表演、道具互动和结束状态。]

**台词：** [每条发言单独一行：起始秒-结束秒s人物：核实后的中文台词；时间按当前segment计。没有可信对白时写“无明确台词。”]

**背景音效：** [环境声、拟音和动作重音；默认无BGM。]

**禁止项：** [本段最容易生成错误的身份、数量、形体、位置、文字和连续性问题。]
```

运镜、效果转场与切镜的选择、明确画面方向、新增过渡加时及段内时间同步，统一遵循[视频提示词编写规则§4](../../character-scene-style/references/视频提示词编写规则.md)。正文不单列转场执行秒数；不得因旧格式示例而恢复固定总长或默认硬切。

## 写作规则

- 旧格式同样执行共享规则的冗词检查：不写“结束时保留上述动作落态”“不提前发生下一镜事件”等空泛句，不用同义套话填充；具体动作与必要连续性直接写明。
- 每段保持为一个连贯、可直接复制使用的提示词单元；**第一棒零占位符一步到位写死完整画风母词与人物造型**（`fill-style` 仅作跨集画风二次统一刷新备用，严禁初稿留任何占位符并由 `verify-script-alignment` 拦截检查）。
- 明确人物和物体的数量、颜色、相对位置、真实俯仰角、非摆拍视线向量及状态变化（严禁正面盯镜头并排罚站摆拍）；场景母图严格区分跨时间线/事件状态（防 `SCENE_TEMPORAL_STATE_CONFLICT`）并遵守净空三禁（旗杆留空禁挂旗帜、禁现代交通标志、禁英文乱码与小字牌匾）。
- 标题应概括画面事件，不凭空添加剧情。
- 画面允许出现剧情或设计需要的文字，包括招牌、书信、界面、字幕等；不默认添加“无文字”“禁止文字”“禁止字幕”等一概排除文字的提示词。按原片与当前设计要求确定内容和位置，人物改名涉及的文字同步新姓名；自查核对错字、漏字及可读性。水印、平台/工具标识和其他非用户要求的标识仍按无标识规则排除，非剧情片头片尾仍按既定规则处理。
- 不把推测写成原声台词。听不清的词标为 `〔待核〕`，可信度不足则写“无明确台词。”
- 外语对白默认译成自然中文，并在文档说明中注明“根据原声翻译”。
- 对不足标准时长的最后一段照实描述，不扩写成完整时长。
